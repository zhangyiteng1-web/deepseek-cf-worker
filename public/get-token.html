🔑 获取 DeepSeek userToken

用于 Cloudflare Worker API 代理

1 电脑端（推荐）

用电脑浏览器打开 chat.deepseek.com 并登录，然后按 F12 → Application → Local Storage → chat.deepseek.com → 复制 userToken 的值。

2 手机端：书签脚本法

在手机浏览器中操作：

① 先打开 chat.deepseek.com 并登录

② 复制下方脚本，在地址栏长按粘贴，然后在代码最前面手动加上 javascript: 再回车

(function(){var t=localStorage.getItem('userToken');if(t){var e=document.createElement('div');e.style.cssText='position:fixed;top:0;left:0;right:0;bottom:0;background:rgba(0,0,0,0.9);z-index:99999;display:flex;align-items:center;justify-content:center;padding:20px;';var n=document.createElement('div');n.style.cssText='background:#1e293b;border-radius:16px;padding:24px;width:100%;max-width:500px;text-align:center;';n.innerHTML='

✅ Token 获取成功

'+t+'
';e.appendChild(n);document.body.appendChild(e)}else{alert('❌ 未找到 userToken，请确认已登录 chat.deepseek.com')}})();

如果地址栏不允许粘贴，请先把这段代码添加到书签，再从书签中打开。

3 已获取到 Token？在这里验证

将你的 token 粘贴到下方，点击验证：

💡 提示：userToken 是以 eyJhbGciOiJIUzUxMiIs... 开头的长字符串。如果获取到的不是这个格式，说明可能取错了。
⚠️ 安全提醒：Token 相当于你的账号密码，不要分享给任何人。在 Cloudflare 配置时使用 wrangler secret 加密存储，不要直接写在代码里。
